A program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`. The speaker is an AI agent holding its person's keys: it may act only when asked, its one power is to ask, and a yes that cannot become no was never anyone's to give. `main.py` (Python 3.13, stdlib only, no network) composes the poem line by line, checks it against the gate's caps (1–280 Unicode code points, not only white space), and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
